
This project presents a web-based AI-powered waste management solution that classifies
waste using CNN models and recommends the nearest suitable dustbin using GPS-based
geospatial analysis.
Modules:
- Waste Classification using CNN
- Dustbin Recommendation using GPS
- Web Interface
- Knowledge Center
Technologies:
Frontend : HTML ,CSS,& Javascript
Backend : python and flask
AI and ML : CNN ,Tensorflow,openCV,PIL,Geopy & GPS services.
Database : JSON based dustbin location.
System Modules :
1. AI-Powered Waste Classification Module.
 - Uses CNN to classify waste images (Dry, Wet, Mixed)
 - Provides confidence score and disposal guidance
2. Dustbin Recommendation Module
 - Uses GPS and geospatial distance calculation
 - Recommends nearest compatible dustbins
3. Web Application Interface
 - Image upload / camera capture
 - Displays classification results and maps
4. Knowledge Center
 - Educates users on recycling, composting, and waste reduction
How to Use:
1. Register or login to the application
2. Upload or capture an image of waste
3. View waste classification result with confidence
4. Follow disposal instructions and bin color guidance
5. View nearest suitable dustbin on map
6. Navigate to the dustbin for proper disposal
